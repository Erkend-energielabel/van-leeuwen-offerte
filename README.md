# Van Leeuwen Glasbewerking – offerte-app

Enkele HTML-app voor het maken van glas- en ventilatie-offertes, facturen, zaaglijsten en calculaties.

- `template.html` is de bron. Het logo en de glasgegevens worden door `build.py` in de app gezet.
- `index.html` is het resultaat na bouwen.

Bouwen: `python3 build.py` (zet de logo- en glasgegevens in `index.html`).
